# Dot Lattice Art

A full-viewport page displaying the original animated artwork by [0xSero](https://x.com/0xSero/status/2116252586961698900), played silently on a loop against its matching charcoal background. The loop uses an eight-second cycle from the original video, excluding its introductory fade.

The artist's dot-lattice tools and examples are available at [0xSero/ascii-art](https://github.com/0xSero/ascii-art). The video is the original from the linked post; it is not part of the MIT-licensed code in that repository.
